# PYP: Prompt_Your_Problems - Mental Health Support App
(Still Under Development)(New UI/UX and features in pipeline)
A Flutter-based mobile application, **PYP (Prompt_Your_Problems)**, aimed to offer mental health support and resources to users. This app provides a welcoming, user-friendly experience that combines an AI-powered chatbot, relaxation tools, and access to professional mental health resources.

## Features

- **Welcoming Interface**: Displays motivational messages to uplift users.
- **AI-powered Chatbot**: Provides instant support and coping strategies.
- **Mental Health Assessment Quiz**: Helps users assess their mental health.
- **Relaxation Music Player**: Plays calming music and various healing frequencies.
- **Mini-games**: Offers fun, stress-relieving games.
- **Directory of Mental Health Professionals**: Easy access to professionals for further support.

## Getting Started

### Prerequisites

- Flutter SDK
- Dart
- Android Studio or VS Code with Flutter extensions

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/pyp_iic_wf.git
   ```

2. Navigate to the project directory:
   ```bash
   cd pyp_iic_wf
   ```

3. Install dependencies:
   ```bash
   flutter pub get
   ```

4. Run the app:
   ```bash
   flutter run
   ```

## Project Structure

- `main.dart`: Entry point of the application.
- `welcomepage.dart`: Initial welcome screen with motivational messages.
- `homepage.dart`: Main navigation hub for accessing different app features.
- `assessment.dart`: Mental health assessment quiz screen.
- `menu.dart`: Menu for navigating features like music, games, and assessments.
- `chatbot.dart`: Interface for the AI-powered chatbot.
- `music.dart`: Relaxation music player for stress relief.
- `games.dart`: Mini-games for stress relief.
- `doctor.dart`: Directory of mental health professionals.

## Dependencies

- **Flutter**: The primary framework for building the app.
- **audioplayers**: Used to play relaxation music and audio.
- Additional dependencies can be found in the `pubspec.yaml` file.
